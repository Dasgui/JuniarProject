## Старт
Для запуска программа необходимо будет скачать приложение Docker Desktop, так как само приложение и его база размещены в контейнере.
После успешной загрузки и запуске Docker Desktop, вам необходимо будет выполнить ниже представленные команды:
```
# Запуск
docker-compose up --build

# Или через Makefile
make run

# Сервер будет доступен по адресу:
# http://localhost:8081/products
```

###  Для остановки приложения
```
docker compose down
```

### Полный перезапуск (сброс БД)
```
make docker-rebuild
```

## Файл .env
В файле .env вы также можете изменить ip адреса и порты для запуска сервера и базы данных. В случае его отсутствия можете
его создать и вставить ниже представленные переменные. Так как без этого файла запуск приложения будет невозможен.
```
# Переменные остветсвенные за запуск миграции
GOOSE_DBSTRING="host=127.0.0.1 port=5432 user=Comix password=tron dbname=product-store sslmode=disable"
GOOSE_DRIVER=postgres
GOOSE_MIGRATION_DIR=./internal/migrations

DB_HOST=127.0.0.1
DB_PORT=5432
DB_USER=Comix
DB_PASSWORD=tron
DB_NAME=product-store
SERVER_PORT=8081
```

## Библиотеки
Если вы хотите самостоятельно разобрать или по отдельности позапускать компоненты приложения, то лучше сразу скачать все необходимые библиотеки
```
go mod download
```

## API Документация
После успешного старта приложения вы также можете проверить имеющейся функционал по следующему адресу:
```
http://localhost:8081/swagger/index.html
```
Для генерации Swagger документации:
```
# Установить swag (если не установлен)
go install github.com/swaggo/swag/cmd/swag@latest

# Сгенерировать документацию
swag init -g cmd/main.go -o docs

# Или через Makefile
make swag
```

## Миграция (создание) таблиц
После успешного старта приложения будет создана таблица с уже подготовленными данными, так что вам не придется делать миграцию вручную, но если вы захотите запустить миграцию самостоятельно,
то вам понадобятся следующие команды (стоит отметить что миграция будет возможно если сама база данных предварительно запущена):
```
# Установка библиотеки Goose поможет нам выполнять миграцию
go install github.com/pressly/goose/v3/cmd/goose@latest

# Если вы хотитет создать свою новую миграцию (МОЖЕТ ПЕРЕЗАПИСЫВАЕТ УЖЕ СОЗДАННЫЙ ФАЙЛ! БУДЬТЕ ОСТОРОЖНЫ!)
# После создания вам будет необходимо заполнить созданный файл
goose -s create create_some sql

# Запускает миграцию в каждом созданном sql файле
goose up

# Отменяет выполненую миграцию
goose down
```


## Makefile команды
Данные команды смогут выполниться лишь при наличии утилиты make. Тяжело дать какие-то рекомендации по её установке
так как тут многое зависит от операционной системы. В операционных системах Linux данная утилита идёт по умолчанию.
Так что если вам захочется пользоваться Makefile, вам придется узнать как установить данную утилиту на вашу операционную систему.
```
# Работает при запущеном приложение Docker Desktop
make run         # Запуск сервера
make docker-rebuild  # Перезапуск сервера

#Работает в случае если сама база данных работает и скачана библиотека Goose
make migrate  #Запускает миграцию
make drop-bd  #Удаляет созданные таблицы

make test  # Запускает тесты
```
